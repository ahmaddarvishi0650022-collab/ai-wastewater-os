پشتیبان‌گیری و مدیریت داده‌ها

ذخیره‌سازی محلی روی مرورگر همین دستگاه؛ انتقال فایل پشتیبان برای نگهداری امن ضروری است.

اطلاعات در این نسخه در حافظه محلی مرورگر ذخیره می‌شود و به‌صورت خودکار بین گوشی و رایانه همگام‌سازی نمی‌شود. پاک‌کردن داده‌های مرورگر ممکن است اطلاعات را حذف کند؛ مرتباً نسخه پشتیبان JSON بگیرید.

بازیابی اطلاعات

فایل پشتیبان JSON این سامانه یا ساختار قدیمی نسخه ۶ را انتخاب کنید. بازیابی، داده‌های فعلی را جایگزین می‌کند.

راهنمای نگهداری داده

  1. پس از هر دوره ثبت اطلاعات، فایل JSON پشتیبان دریافت کنید.
  2. فایل پشتیبان را در رایانه و یک فضای امن دیگر نگهداری کنید.
  3. برای انتقال داده بین گوشی و رایانه، از خروجی JSON و سپس بازیابی در دستگاه دوم استفاده کنید.
  4. CSV برای تحلیل در Excel مناسب است؛ JSON برای بازیابی کامل اطلاعات استفاده می‌شود.
  5. این نسخه فاقد حساب کاربری، رمزنگاری سمت سرور و همگام‌سازی ابری است.
